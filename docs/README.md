# NOC for FGT Product Website

Static product website for GitHub Pages.

## Files

- `index.html`: product landing page
- `privacy.html`: standalone privacy policy
- `terms.html`: standalone user agreement
- `assets/styles.css`: site styling
- `assets/images/`: product logo and screenshots

## GitHub Pages

1. Upload the contents of this folder to a GitHub repository.
2. In GitHub, open `Settings` -> `Pages`.
3. Select the branch and root folder that contain `index.html`.
4. Publish.

No build step is required.
