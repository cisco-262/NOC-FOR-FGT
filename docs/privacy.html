Privacy Policy

1. Overview

NOC for FGT is a local-first FortiGate monitoring companion. The app connects from the user's iPhone or iPad to FortiGate devices configured by the user. Direct device monitoring does not require a NOC for FGT cloud account.

2. Website Data

This static website does not include account registration, contact forms, advertising trackers, or analytics scripts. Hosting providers can process basic technical logs such as IP address, user agent, request time, and requested URL under their own policies.

3. Device Configuration Data

The app stores FortiGate device records locally on the user's device. These records include device names, hosts or IP addresses, HTTPS management ports, usernames, user preferences, certificate trust settings, and certificate fingerprint metadata where applicable.

4. Credentials and Authentication Data

FortiGate passwords are stored locally using the iOS Keychain. FortiToken / OTP codes are used for authentication and are not included in backups. Backup exports do not include passwords, OTP codes, session cookies, CSRF tokens, authorization headers, API tokens, bearer tokens, or Keychain secrets.

5. Monitoring and History Data

The app stores monitoring information locally to support device status and historical trend views. This can include system health, CPU, memory, active sessions, interface status, WAN traffic, topology-related interface information, diagnostics, and locally collected history samples.

6. App Lock

Optional App Lock can use Face ID, Touch ID, or device passcode through Apple's local device authentication APIs to help protect access to saved devices and monitoring data. App Lock protects access to the app interface when enabled; it does not replace iOS device security or FortiGate account security.

7. Certificate Trust

When the user enables a trusted certificate option, the app records certificate fingerprint information locally to help identify certificate changes during future connections. Certificate names and chain information can be shown for visibility. User-controlled certificate trust determines whether an exception is allowed.

8. Backup and Restore

Backup exports are for app configuration migration and recovery. Exported device data can include device name, host, port, username, certificate trust preference, and reference certificate fingerprint metadata. Authentication secrets are excluded from backup exports.

9. Data Sharing

NOC for FGT does not sell personal data. The app does not use advertising trackers or analytics SDKs. Data is shared only when required to operate user-requested services, comply with law, protect rights and safety, or diagnose issues that the user intentionally reports.

10. Retention and Deletion

Device records, preferences, monitoring history, and certificate trust metadata remain on the user's device until the user deletes them or removes the app. Device deletion uses the app's local cleanup path to remove associated local device data and stored credentials where supported by the platform.

11. User Responsibility

Users are responsible for connecting only to FortiGate devices and networks they own or are authorized to manage, and for protecting device credentials, network access, and exported diagnostic material.

12. Changes

This policy can be updated as the product evolves. Material changes are reflected by updating the effective date on this page.

13. Contact

For privacy requests, contact support@opshome.run.
