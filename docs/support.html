Getting started

From device setup to monitoring.

Step 1 - Add your device

  • Device name
  • IP address or hostname
  • HTTPS management port
  • Username
  • Password

Step 2 - Connect

NOC for FGT connects directly from your iPhone or iPad to the FortiGate address you configure.

Make sure your iPhone or iPad can reach the FortiGate management interface on the network you are using.

Step 3 - Monitor

  • System health
  • CPU and memory
  • Active sessions
  • Interfaces and WAN traffic
  • Topology and FortiGuard status
  • Historical trends and diagnostics

Connection & login

Check reachability before assuming the password is wrong.

  1. Confirm the FortiGate address is reachable.
  2. Confirm HTTPS management access is enabled.
  3. Confirm the management port.
  4. Confirm the username and password.
  5. Confirm the account has permission to view the required status information.
  6. If 2FA is enabled, enter the requested FortiToken / OTP code.

Hostname / IP

You can connect using the hostname or IP address configured for your FortiGate management interface. Local Network permission may be required by iOS when connecting directly to a FortiGate on your LAN.

HTTPS / Certificate Trust

Some FortiGate environments use self-signed or privately issued certificates. NOC for FGT may allow user-controlled certificate trust depending on the configured connection.

Two-factor authentication

Use the code from your configured FortiGate account.

If FortiToken / OTP-based two-factor authentication is enabled on the configured FortiGate account, NOC for FGT will request the authentication code during sign-in.

NOC for FGT does not generate or replace FortiToken codes.

Demo Mode

Explore the app without real device access.

NOC for FGT includes a built-in Demo Mode that lets you explore the main monitoring experience without connecting to a physical FortiGate.

  • No physical FortiGate required
  • No FortiGate credentials required
  • No external NOC for FGT account required
  • No VPN required for Demo Mode

Monitoring

System and network visibility.

NOC for FGT can display system and network monitoring information such as CPU, memory, active sessions, interfaces, and traffic.

Historical trends

History depends on the environment and local samples.

Historical views are available for supported operational metrics. The amount of history available can depend on the FortiGate environment and locally collected samples.

Backup & restore

Move supported configuration without exporting secrets.

NOC for FGT can export and import supported device configuration information.

Backup files do not include passwords, OTP codes, session cookies, CSRF tokens, or other authentication secrets.

Common troubleshooting

Practical checks for common symptoms.

Cannot connect to the FortiGate

  • Configured IP or hostname
  • HTTPS management access
  • Management port
  • Current network reachability
  • Username and password
  • Administrator permissions

Login works in a browser but not in the app

Confirm that the app is using the same hostname/IP and HTTPS port as the browser. Also check whether the environment uses a self-signed/private certificate, two-factor authentication, or network restrictions.

Some metrics are missing

Available metrics can vary by FortiGate model, FortiOS version, VDOM configuration, administrator permissions, and enabled services.

WAN history is unavailable

Device-side WAN history can depend on the FortiGate configuration and available monitoring data. NOC for FGT may fall back to locally collected traffic samples when device history is unavailable.

FAQ

Answers for setup and review.

Why does iOS ask for Local Network access?

NOC for FGT may need Local Network access when connecting directly to a FortiGate on your LAN. This permission allows the app to communicate with devices on the local network. You can review the permission later in iOS Settings.

Why do I only see recent or live data?

Historical availability depends on the FortiGate model, FortiOS version, administrator permissions, enabled services, and locally collected samples. When device-side historical data is unavailable, NOC for FGT can continue building local history while the app is used.

Can I monitor multiple FortiGate devices?

Yes. NOC for FGT supports managing multiple configured FortiGate devices from the app.

Why do I need to enter my password again after importing a backup?

Authentication secrets are intentionally excluded from backup exports. After importing a device configuration, enter the credentials again on your device.

Where is my FortiGate password stored?

FortiGate passwords are stored locally using the iOS Keychain.

Does NOC for FGT require a cloud account?

No separate NOC for FGT cloud account is required for direct device monitoring.

Do I need a VPN?

It depends on how your FortiGate management interface is reachable. NOC for FGT connects to the address you configure. For remote access, use an appropriate secure network path for your environment.

Which FortiOS versions have been tested?

The app has been tested with FortiOS 6.2 and 7.2 environments. Available information can vary by model, firmware version, administrator permissions, and enabled features.

What is Diagnostics?

Diagnostics provides technical information that can help explain connection, API endpoint, compatibility, and monitoring behavior.

Why is my 2FA code not requested?

Confirm that two-factor authentication is enabled for the FortiGate administrator account you configured.
